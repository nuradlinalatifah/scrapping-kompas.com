# Scraping Kompas

Repository ini dibuat untuk tugas scraping dan preprocessing data berita dari website Kompas.

## Isi Repository

- `Scrapping.py` → kode untuk mengambil data berita dari Kompas
- `Preprocessing.ipynb` → proses membersihkan dan mengolah data hasil scraping
- `berita_kompas_raw.csv` → data berita yang diperoleh dari proses scraping
- `berita_kompas_prepro.csv` → data setelah dilakukan preprocessing

## Proses

Data berita diambil dari website Kompas menggunakan Python. 
Data yang sudah didapat kemudian disimpan dalam bentuk CSV dan dilakukan preprocessing untuk membersihkan data teks.
